## Task 3 commit candidate

- Buffer layout has the 64-byte template, second half, optional trajectory,
  aligned headroom marker, inline pre-data, and trailing data marker. Constant
  assertions verify offsets, sizes and alignment.
- Single-segment operations use signed current_data relative to data[0]. Flag
  positions and advance/reset/put/push/make_headroom/pull follow vendored
  `vlib/buffer.h`, with the explicitly specified Rust slice bounds from ADR-0007.
- Runtime buffer and buffer_mut return direct references, tied to shared and
  exclusive runtime borrows. Runtime get_buffer/get_buffer_mut Result/guard APIs
  are removed. Address conversion stays in core; the hidden cross-crate unsafe
  entries carry graph ownership obligations and reject mutable shared tails.
- DataPlaneMain is no longer Clone. Node and packet-producing transport calls
  borrow it mutably. Worker lookup accepts the existing thread index, following
  session_main_get_worker and tcp_get_worker. Packet writes finish before
  another runtime access. Existing consumers are migrated without adding
  protocol behavior or new ownership tracking.
- The existing inline Rust single-segment test covers the upstream unittest's
  zero-length cases, signed advance, negative pre-data, reset, append/prepend,
  and the ADR-defined headroom/pull slices. No tests were executed.
- The worktree already contained uncommitted BufferMain/raw Index prerequisites
  on resumption. They are retained as required by these Buffer operations.
