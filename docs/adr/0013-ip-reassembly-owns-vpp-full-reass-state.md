# IP reassembly owns VPP full-reassembly state

IP full reassembly is owned by a deep IP Reassembly module, not by graph-node choreography. The module keeps a per-Data-Worker `Pool` of Fragment Contexts, a shared Fragment Owner Bihash whose opaque values pack context pool index with Memory Owner Worker, Memory Owner versus Sendout Worker roles (Sendout set only on offset-0), inline reassembly tracing, and expiry. `IpReassemblyNode` only drains the Pending Frame and performs Graph Fanout for worker-local `Input` / `Drop`; cross-worker transfer uses the generic Handoff primitive rather than a reassembly-specific next arc. Completed datagrams re-enter IP Input instead of skipping to Lookup. Failures free context and bihash entries without a sticky failed-key table. This matches VPP `ip4_full_reass.c` ownership (per-thread pool, bihash, dual thread indexes, expire-walk, handoff, return to input) while keeping Hammer's Fanout and Handoff layer contracts.
