# Data-plane primitives live in hammer-core

Hammer's packet buffer, frame, and graph identity primitives belong in `hammer-core`, including data-plane buffers, buffer indexes, frame indexes, buffer frames, frame pool ownership, packet cursors, `Frame<Next>` / `Frame<Pending>` RAII ownership, node ids, node handles, node kinds, node states, node registrations, and next-arc label traits. This expands `hammer-core` from general base types into the owner of shared data-plane primitives, while `hammer-runtime` composes those primitives into graph scheduling and dispatch. `hammer-infra` remains the owner of generic structures such as pools, slices, heaps, hash tables, trees, timers, SIMD, prefetch, rings, and FIFOs; it is not merged into core. The old `hammer-adapter` crate must not retain buffer/frame ownership implementation or graph identity definitions to keep the old crate placement alive.
